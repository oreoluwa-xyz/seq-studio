# SEQ Studio

Browser companion for the SEQ music composition platform.

[Open Studio](https://oreoluwa-xyz.github.io/seq-studio/ui/)

This repository contains the published static UI, manual, and module format documentation. Firmware installation requires the desktop app or local service. Web MIDI features require a supported browser and MIDI permission. Drafts are stored in your browser.
